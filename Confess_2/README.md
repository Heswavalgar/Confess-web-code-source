# 💌 Hellowww — Interactive Confess Web

> Sebuah website confess interaktif yang dibuat seperti surat digital sederhana, 
> dengan animasi lembut dan alur cerita yang berjalan halaman demi halaman.

Website ini dibuat untuk menyampaikan sebuah pesan secara perlahan,
mulai dari pembuka, cerita kecil, sampai akhirnya masuk ke bagian confess.

---

## 🌷 Tentang Website

`Hellowww` adalah website confess dengan konsep **digital letter**.

Alih-alih menampilkan seluruh pesan dalam satu halaman, isi confess
dibagi menjadi beberapa halaman yang dapat dinavigasi secara interaktif.

Alurnya dibuat bertahap:

**Opening → Story → Realization → Confession → Closing**

Website terdiri dari **9 halaman**, termasuk cover dan halaman finale.

---

## ✨ Fitur

- 💌 Confess berbentuk surat digital
- 📖 Sistem halaman dengan transisi
- 👆 Navigasi menggunakan tombol
- 👉 Dukungan swipe untuk berpindah halaman
- ⌨️ Navigasi menggunakan keyboard
- 🎵 Background music
- ✨ Animasi text reveal
- 💫 Floating letters sebagai elemen atmosfer
- ❤️ Animasi gambar hati pada halaman terakhir
- ✨ Efek spark setelah finale
- 📱 Responsive untuk perangkat mobile
- ♿ Dukungan `prefers-reduced-motion`

---

## 🎨 Konsep Visual

Website menggunakan gaya visual yang minimalis dan soft dengan
kombinasi:

- Warna beige / off-white
- Tipografi handwritten
- Serif italic
- Aksen warna dusty rose
- Tekstur grain
- Animasi yang ringan
- Banyak ruang kosong untuk memberikan kesan tenang

Font yang digunakan adalah:

**Caveat · Cormorant Garamond · DM Mono**

---

## 📖 Alur Halaman

### 00 — Cover

Halaman pembuka dengan tulisan:

> Hellowww

Pengunjung dapat menekan tombol **tap to open** untuk memulai.

### 01 — Opening

Memulai isi surat dengan sebuah pembuka sederhana.

### 02 — Realization

Bagian pendek yang mulai membangun suasana dan rasa penasaran.

### 03 — Little Things

Menceritakan bagaimana hal-hal kecil perlahan menjadi sesuatu
yang diingat.

### 04 — The Question

Bagian reflektif mengenai kapan sebenarnya rasa itu mulai muncul.

### 05 — Silence

Sebuah halaman kosong dengan `......` sebagai jeda sebelum confession.

### 06 — Confession

Bagian utama dari website.

> And..... i like youuuu

### 07 — Closing

Pesan penutup tanpa memberikan tekanan atau ekspektasi.

### 08 — Finale

Penutup terakhir dengan animasi hati dan pesan terima kasih.

---

## 🎵 Musik

Website mendukung background music menggunakan file:

`music.mp3`

Letakkan file musik di lokasi yang sesuai dengan source code agar
audio dapat dimainkan.

Pengunjung juga dapat mengontrol musik melalui tombol musik yang tersedia.

---

## 🛠️ Teknologi

Website ini dibuat menggunakan:

- HTML
- CSS
- JavaScript
- SVG
- Google Fonts

Tidak menggunakan framework atau library JavaScript tambahan.

---

## 📱 Responsif

Tampilan telah disesuaikan untuk perangkat mobile.

Pada layar yang lebih kecil, layout beberapa bagian akan berubah agar
tetap nyaman digunakan pada smartphone.

---

## 📝 Kustomisasi

Website dapat diubah sesuai kebutuhan.

Beberapa bagian yang dapat dikustomisasi:

- Judul
- Isi pesan
- Nama
- Tanggal
- Warna
- Font
- Musik
- Animasi
- Jumlah / isi halaman

Sebagian besar isi pesan dapat ditemukan langsung di dalam file
`index.html`.

---

## 🌐 Cara Menjalankan

Tidak membutuhkan instalasi khusus.

Cukup buka:

`index.html`

di browser.

Untuk digunakan secara online, project dapat dipublikasikan melalui
layanan hosting website statis seperti GitHub Pages, Netlify, atau Vercel.

---

## ⚠️ Catatan

Beberapa aset eksternal seperti font dan musik membutuhkan file atau
koneksi yang sesuai agar dapat digunakan.

Pastikan memiliki hak atau izin untuk menggunakan aset yang dimasukkan
ke dalam versi website yang dipublikasikan.

---

## 💌 Penutup

Website ini dibuat untuk satu hal sederhana:
